# Core User Flows — Ironclad Sentinel

### Flow 1: High-Intent Conversion
Visitor arrives → Reads hero value proposition → Clicks "Request Security Audit" → Modal opens with pre-selected service → Submits form → Toast confirms transmission.

### Flow 2: Exploration & Validation
Visitor scrolls to Offerings → Inspects Cybersecurity Suite → Scrolls to Testimonials → Reads FAQ accordion → Initiates inquiry.
