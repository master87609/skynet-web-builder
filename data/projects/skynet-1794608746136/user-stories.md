# User Stories — Ironclad Sentinel

- **US-01:** As a prospect, I want to clearly comprehend what Ironclad Sentinel offers within 3 seconds of landing so I can evaluate if it fits my needs.
- **US-02:** As a customer, I want to explore Cybersecurity Suite and Threat Engine with transparent details.
- **US-03:** As a mobile visitor, I want a frictionless navigation drawer and rapid touch response.
- **US-04:** As an interested lead, I want to submit my information via an interactive modal and receive immediate confirmation.
