Write an async Python function to compute Fibonacci numbers with memoization and provide time complexity analysis.
AI

Here is an optimized asynchronous implementation with O(N) time complexity and O(N) space complexity:

import asyncio
from functools import lru_cache

@lru_cache(maxsize=1024)
def _fib_sync(n: int) -> int:
    if n < 2:
        return n
    return _fib_sync(n - 1) + _fib_sync(n - 2)

async def compute_fibonacci(n: int) -> int:
    loop = asyncio.get_running_loop()
    return await loop.run_in_executor(None, _fib_sync, n)
