# Core User Flows — Velvet & Ember

### Flow 1: High-Intent Conversion
Visitor arrives → Reads hero value proposition → Clicks "Reserve a Table" → Modal opens with pre-selected service → Submits form → Toast confirms transmission.

### Flow 2: Exploration & Validation
Visitor scrolls to Offerings → Inspects Bakery Suite → Scrolls to Testimonials → Reads FAQ accordion → Initiates inquiry.
