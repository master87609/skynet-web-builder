# user-stories.md

## 1. As a Conscious Foodie, I want to view the upcoming weekly menu and ingredient origins so that I can choose loaves that match my taste preferences and dietary needs.
- **Acceptance Criteria:**
  - Menu displays item photos, crumb profiles, fermentation times, and flour origins.
  - Clear labels for vegan, organic, and whole-grain options.
  - Ability to view items that are "Coming Soon" before ordering opens.

## 2. As a Conscious Foodie, I want to reserve a limited-batch sourdough loaf and select a specific pickup date and time slot so that I am guaranteed my bread without waiting in line.
- **Acceptance Criteria:**
  - Real-time inventory counter shows remaining stock for each loaf.
  - User can select from available time slots on designated bake days.
  - Checkout prevents selection of fully booked time slots.

## 3. As a Conscious Foodie, I want to use a fast guest checkout with Apple Pay / Google Pay so that I can secure limited inventory quickly before it sells out.
- **Acceptance Criteria:**
  - One-click express checkout options available on product and cart pages.
  - Option to save shipping/pickup preferences for registered accounts.
  - Immediate on-screen confirmation and receipt generation.

## 4. As the Artisan Baker / Owner, I want to configure weekly product quantities and bake-day time slots through an admin panel so that I never oversell my physical baking capacity.
- **Acceptance Criteria:**
  - Admin dashboard allows setting daily max limits per SKU.
  - System automatically marks items as "Sold Out" when capacity hits zero.
  - Ability to pause or close ordering windows manually.

## 5. As the Local Pickup Coordinator, I want to generate a sorted, printable packing list of all preorders for a specific pickup window so that I can efficiently bag orders and minimize customer wait times.
- **Acceptance Criteria:**
  - Admin view can filter preorders by date and time slot.
  - List displays customer name, ordered items, and payment status in a checklist format.
  - Option to export data to CSV or print directly from the browser.

## 6. As a Conscious Foodie, I want to receive automated email and text message reminders about my upcoming pickup window so that I don't forget to collect my fresh bread.
- **Acceptance Criteria:**
  - Automated confirmation sent instantly upon order completion.
  - Reminder notification dispatched 24 hours prior to the pickup slot.
  - Notifications include pickup address, parking instructions, and order details.

## 7. As the Artisan Baker / Owner, I want to view sales summaries and popular product trends on an analytics dashboard so that I can plan future grain purchases and dough batch sizes.
- **Acceptance Criteria:**
  - Dashboard visualizes total revenue and order volume over weekly/monthly periods.
  - Identifies top-selling loaves and recurring customer metrics.
  - Accessible via responsive mobile and desktop admin views.
